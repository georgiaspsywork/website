# How to change your website

You don't need to know anything technical. You tell Claude what you'd like in ordinary words, Claude makes the change, and you check it on a private preview before anything goes live.

---

## 1. Getting started

1. Go to **claude.ai/code** (or open Claude Code in the Claude app) and choose **New session**.
2. When it asks for a repository, pick **georgiaspsywork/website**.
3. If you're offered a choice of branch, pick **preview**. (This is the safe copy of your site. Nothing you do there reaches the public until you say so.)
4. Say hello, for example: *"Hi, I'd like to make some changes to the website."*

Claude will switch itself to the preview copy at the start of every session, so even if the branch box isn't there or says something else, you're safe.

You can start a fresh session each time you have changes to make. Nothing is lost: everything that was saved earlier is still there.

---

## 2. How a change works

1. **You ask.** Say what the site says now and what you'd like instead.
2. **Claude makes the change** and checks it hasn't broken anything.
3. **Claude gives you a preview link.** It looks exactly like the real site, but only people with the link can find it.
4. **You look, then say what you think.** Happy? Say so. Not quite right? Say what to adjust and Claude will do it again.
5. **When you're happy, say "publish it".** Claude will tell you exactly what is about to go live and wait for you to say yes. Only then does the public site change.

Preview first, publish second. You can ask for as many tweaks as you like before publishing.

---

## 3. Asking for changes

Just say it the way you'd tell a colleague. You don't need to say which page or what it's called.

**Changing words**
- *"The home page currently says 'Fatigue is a design problem'. I'd like it to say 'Fatigue is a design choice'."*
- *"Somewhere on the About page it says I've worked in the sector for 15 years. It should be 18."*
- *"Change my phone number to 07700 900123 everywhere it appears."*

**If you're not sure where something is**, describe it or paste a bit of it:
- *"There's a sentence about tired people briefing people who've just woken up. I want to soften it."*

Claude will find it. If the same words appear in more than one place, or it can't tell which you mean, it will ask, for example *"Is that the heading on the Home page, or the one on the Resources page?"*, and show you what each says now. Just answer in a word or two.

**Using a link or screenshot**
- *"On this page [paste web address], change the second heading to 'What we do'."*
- Drag a screenshot into the chat and say *"Can you change the text in the red box?"*

**Pictures**
- Drag the photo into the chat: *"Please put this photo at the top of the About page. The caption should be 'Georgia at a site visit'."*
- Big photos are fine. Claude shrinks them so the site stays fast. If you don't say what the photo shows, Claude will ask, because the description helps visually impaired visitors.

**Adding an article**
- Attach your Word document (or, if connected, share a Google Doc link): *"Please turn this into a new article."*
- Claude will ask for anything it can't find, such as the date or a one-line summary. It never makes anything up.

**Adding a resource** (a download, template or guide)
- Attach the file: *"Please add this as a new resource called 'Handover checklist'."*

**Adding a new page**
- *"I'd like a new page for my services."* Claude will first ask which kind of page you'd like: a standard page, an article, or a resource page. If you're not sure, say so and it will explain.
- *"And add it to the menu at the top."*

**Changing the menu, footer or contact details**
- *"Add a Press link to the footer."*
- *"My email address has changed to …"*

**Looking before you leap**
- *"Can you show me how the home page looks on a phone?"*

---

## 4. Words and phrases that work

| You want to… | Say something like… |
| --- | --- |
| See your changes | *"Let me see it"* or *"preview it"* |
| Go live | *"Publish it"* or *"make it live"* |
| Check the whole site | *"Show me screenshots of every page"* |
| Undo something | *"I've changed my mind about that last change, put it back."* |
| Find out what's unfinished | *"What on the site is still placeholder?"* |

---

## 5. Good to know

- **Nothing is public until you say "publish it".** Claude always shows you a summary first and waits for a clear yes.
- **Your exact wording is used.** Claude won't rewrite or add claims. If it spots what looks like a typo, it will tell you.
- **If something isn't right on the live site**, tell Claude what you see and it will put it right (it can undo recent changes).
- **The forms don't send anything yet.** The Contact and newsletter forms only look right for the moment. Ask Claude to set them up when you're ready.
- **Some content is still placeholder** (it's marked as such). Ask Claude for a list at any time.
- If Claude asks a question, a short answer is enough. If you don't know the answer, say so.

---

## 6. If you get stuck

- Try rewording: *"Here's what I'm seeing… here's what I'd expected."*
- Start a new session and say what you were doing. Claude can see the history of what has been changed.
- Anything you'd rather not do yourself, just ask. That's what Claude is there for.
